# Madha AI - User Guide

This is your advanced "1000 Legion Power" AI Assistant, built with Python and Flet.

## Features
- **Smart Chat**: Powered by Google Gemini.
- **System Control**: Ask "What is my battery?" or "System status".
- **Internet Search**: Ask "Search for latest Python news" (Uses DuckDuckGo).
- **Study Helper**: Generate smart notes for exams.
- **Quiz Master**: Auto-generate interactive quizzes.
- **Coder Mode**: Describe a UI ("Red login button") and click "Preview in Browser".

## How to Run

1. **Install Dependencies** (If you haven't already):
   ```bash
   pip install flet google-generativeai requests psutil duckduckgo-search
   ```

2. **Start the App**:
   Double-click `start_madha.bat` 
   OR run:
   ```bash
   python src/main.py
   ```

## Requirements
- Python 3.10+
- Internet Connection (for Gemini & Search)

## 🌟 About

**Medha AI** is a cutting-edge, multi-modal AI assistant designed to revolutionize the way you learn, code, and interact with technology. Powered by **Groq** and **Google Gemini**, Medha offers:

- 🧠 **Intelligent Chat** - Natural conversations in Hindi & English
- 📚 **Smart Study Notes** - AI-generated comprehensive study materials
- 🎯 **Interactive Quizzes** - Test your knowledge with adaptive quizzes
- 💻 **Code Generator** - Build full-stack projects with AI assistance
- 🎤 **Voice Control** - Hands-free interaction with voice commands
- 💾 **Session History** - ChatGPT-like persistent chat history
- 🔍 **Real-time Web Search** - Get latest information from the web

## 🚀 Installation

### Windows

```bash
# Clone the repository
git clone https://github.com/Abhimanyuraj8252/Medha-Ai.git
cd Medha-Ai

# Create virtual environment
python -m venv .venv
.venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the app
python src/main.py
```

### Linux/Mac

```bash
# Clone the repository
git clone https://github.com/Abhimanyuraj8252/Medha-Ai.git
cd Medha-Ai

# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the app
python src/main.py
```

## 📱 Build Android APK

### Method 1: GitHub Actions (Recommended)

APK automatically builds on every push!

1. **Check Build Status:** [Actions Tab](https://github.com/Abhimanyuraj8252/Medha-Ai/actions)
2. **Download APK:** Click latest workflow → Artifacts → Download
3. **Install:** Transfer APK to Android device and install

### Method 2: Local Build (WSL)

```bash
# Install WSL
wsl --install

# Inside WSL
sudo apt update
sudo apt install -y python3-pip git openjdk-17-jdk
pip3 install buildozer

# Build APK
cd /path/to/Medha-Ai
buildozer android debug

# Output: bin/medhaai-1.0-debug.apk
```

## 🎮 Usage

### Basic Chat

```python
# Launch the app
python src/main.py

# Type your message in the chat box
# Press Enter or click Send
```

### Study Notes

1. Click **"Study Notes"** tab
2. Enter topic (e.g., "Quantum Physics")
3. AI generates comprehensive notes with:
   - Key concepts
   - Examples
   - Practice questions
   - Web-researched content

### Quiz Mode

1. Click **"Quiz Mode"** tab
2. Enter topic and difficulty
3. Get interactive multiple-choice questions
4. Instant feedback with explanations

### Coder Mode

1. Click **"Coder Mode"** tab
2. Describe your project
3. AI generates:
   - HTML/CSS/JS files
   - Python/Node.js code
   - Full-stack applications
   - Live preview available

## ⚙️ Configuration

### API Keys

Create `src/config.py`:

```python
GROQ_API_KEY = "your_groq_api_key_here"
GEMINI_API_KEY = "your_gemini_api_key_here"
```

### Get API Keys:
- **Groq:** https://console.groq.com/keys
- **Gemini:** https://makersuite.google.com/app/apikey
